# Movie-Data-Analysis-EDA
Movie Data Analysis using Python
# 🔴 Task 3 — Advanced Level: Movie Data Analysis

## 📌 Objective
Created a Jupyter notebook from scratch and conducted a 
complete end-to-end data analysis on a Movies dataset, 
including data cleaning, exploratory data analysis, research 
questions and visualizations to derive meaningful insights.

---

## ❓ Research Questions
1. Which genres generate the highest revenue?
2. What is the relationship between budget and profit?
3. Which years had the most movie releases?
4. Which directors have the highest rated movies?
5. What is the trend of movie ratings over the years?
6. Which languages dominate the film industry?

---

## 🔍 Analysis Workflow
1. **Data Loading** — Loaded dataset into Pandas DataFrame
2. **Data Cleaning** — Handled missing values, duplicates,
   and incorrect data types
3. **EDA** — Explored dataset structure, statistics and 
   distributions
4. **Research Question** — Defined specific questions based
   on dataset
5. **Visualization** — Used multiple chart types to find
   patterns and insights
6. **Conclusions** — Derived meaningful insights from data

---

## 📊 Visualizations Used
- Bar Chart — Genre wise movie count and revenue
- Line Plot — Movie release trend over years
- Scatter Plot — Budget vs Revenue relationship
- Heatmap — Correlation between numerical features
- Histogram — Rating distribution
- Box Plot — Revenue distribution by genre

---

## 🔍 Key Findings
- Action and Adventure genres generate highest revenue
- Higher budget movies tend to have higher box office returns
- Movie releases peaked between 2000-2015
- English language dominates global film production
- Average movie ratings have remained stable over decades
